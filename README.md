# Enterprise Evidence Bench

A reproducible benchmark for enterprise questions whose evidence spans **relational data
and governed documents**, under **per-principal authorization**. It measures whether a
system:
- picks the right sources;
- runs safe SQL;
- keeps unauthorized material out of the model's context;
- cites every material claim;
- abstains when the evidence available to the asking principal cannot support an answer.

The frozen design is in [`docs/spec.md`](docs/spec.md) (v1, byte-frozen).

> **Status: Phase 2a (deterministic corpus and policy substrate).** There is no harness,
> gateway, scorer or reference agent yet. Nothing here should be read as benchmark results.

## What exists today

- **A deterministic generator** for a fictional procurement and supplier-operations company:
  - business units in India, the EU and the UK; INR, EUR and GBP;
  - suppliers, contracts with indexation amendments, POs, receipts, invoices, payments,
    budgets, SLA credits and policy exceptions;
  - a versioned document corpus: contracts, SLAs, policy v1→v2, a stale FAQ, memos,
    incident reports, and restricted finance, risk and legal notes.

  The same seed gives the same bytes on Python 3.11–3.14.
- **Planted cross-source scenarios** with gold facts derived twice (Python from rows; SQL on
  the built database) and doc facts pinned to exact character spans.
- **One access policy, two independent implementations:** Postgres grants plus row-level
  security, and a pure-Python oracle. Generation fails unless they agree on every
  (principal, table, column, row) decision.
- **A case plan:** 665 cases, a group-aware dev/test split, and the frozen corpus
  arithmetic checked on the emitted artifact.

Evidence: [`docs/evidence/phase2a/PHASE2A.md`](docs/evidence/phase2a/PHASE2A.md).

## Quick start

You need Python ≥ 3.11 and a local Postgres 17 you can administer. For example:

```bash
docker run -d --name eeb-pg -e POSTGRES_USER=eebadmin -e POSTGRES_PASSWORD=eebadmin \
  -p 127.0.0.1:55432:5432 postgres:17
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
export EEB_PG_ADMIN_DSN="postgresql://eebadmin:eebadmin@127.0.0.1:55432/postgres"
.venv/bin/eeb build --seed 7 --out instances/seed7          # small scale
.venv/bin/eeb build --seed 7 --scale default --out instances/seed7-default
EEB_REQUIRE_PG=1 .venv/bin/pytest -q
```

The Postgres credentials above are for a throwaway local fixture.

## Data

All data is **synthetic and fictional** and generated by this repository. Every document
carries a synthetic-data marker, and supplier names are screened against a list of
well-known company names. Code: Apache-2.0. Generated data: CC-BY-4.0.

## Prior art

This project builds on and is distinguished from:
- **LayerRAG-Bench:** cross-layer RAG reliability faults.
- **EKRAG:** enterprise document QA.
- **SPARTA:** SQL-centric table+text QA.
- **Insurance-claims RAG with RLS** and **gatekeeper-rag:** permission-aware RAG; the latter
  introduced the independent policy-oracle idea.
- **AgentDojo and BIPIA:** taxonomies for injection attacks.
